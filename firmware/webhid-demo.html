麦点点 · 无障碍点餐盒 WebHID 演示 协议 v2.0.0

⚠️ 请用 Chrome / Edge 桌面版 打开本页，且必须通过 http://localhost 或 https 访问 （直接双击 file:// 打开时浏览器禁用 WebHID）。
本地预览：在 firmware/ 目录下执行 python -m http.server 8000，再访问 http://localhost:8000/webhid-demo.html。
本版本硬件只有 3 个按键（无 LED / 无蜂鸣器），按钮3 额外支持长按。

未连接

按键 ↔ 硬件接线 ↔ 上报码

按键丝印GPIO接法上报码
NEXT 下一个D0GP0一脚接 GPIO，另一脚接 GND0x01（短按）
OK 确定D1GP1一脚接 GPIO，另一脚接 GND0x02（短按）
FINISH 完成D4GP4一脚接 GPIO，另一脚接 GND0x03（短按）
0x04（长按 ≥800ms）

固件已开内部上拉，不需要外接上下拉电阻；未按=高电平 1，按下接地=低电平 0。
按钮3 是"二选一"：短按只会收到 0x03，长按只会收到 0x04，不会先 3 再 4。

收到设备 → 网页 的 HID Input Report（reportId=1）
