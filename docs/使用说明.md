# 麦点点 · 无障碍点餐盒 使用说明

> 让看不清楚、识字困难的人，不靠眼睛也能自己点一顿麦当劳。

## 一、它是做什么的

麦点点是一套「三键实体盒 + 点餐网页」的麦当劳无障碍点餐工具。看不清屏幕、不识字、或手指不便在屏幕上精确定位的人，也能**不靠眼睛、不需打字**，自己独立完成一次点餐。

全程语音播报、大字号、高对比；菜单、价格、套餐组成全部来自**麦当劳官方 MCP 真实调用**。

## 二、两种用法

| 用法 | 怎么用 | 适合 |
|---|---|---|
| **A. 插上就用**（推荐演示） | 把「麦点点」三键盒用 USB 连上电脑，打开网页，全程用三个物理按键 | 线下演示、真实用户试用 |
| **B. 手机/屏幕直接用** | 在支持 WebHID 的桌面浏览器打开网页，用屏幕上的三个大按钮，或键盘 ↑/↓/Enter | 评委、朋友手机/电脑打开链接 |

> 提示：WebHID 当前仅**桌面版 Chrome / Edge** 支持；手机/平板上请用屏幕大按钮，流程完全一致。

## 三、三个键怎么用

盒子上露出三个大键，从左到右：

| 键 | 颜色 | 作用 |
|---|---|---|
| **上一个** | 黄 | 把高亮光标移到**上一项**（往回翻选项） |
| **下一个** | 红 | 把高亮光标移到**下一项**（往前翻选项） |
| **确认·结算** | 白底黄圈 | **单击 = 确认当前项并前进**；**长按约 0.8 秒 = 直接进入结算界面** |

每切换一个选项，网页会**语音播报**当前项名称、价格和说明——不看清屏幕也知道选到了什么。

设计上没有「回退」键：靠「确定还能改选、完成才前进」来容错，避免一层层退回去。

## 四、点餐流程（最多 3 个页面）

1. **开场**：语音问「要套餐还是单点？」→ 上/下选，确认进入。
2. **选品**：
   - **套餐**：列出 5 个高频套餐 → 展开它的真实组成（主食 / 小食 / 饮料逐轮配；固定项自动跳过；冷热、辣度先问），每轮上/下选、确认。
   - **单点**：按「主食·辣 / 主食·不辣 / 小食 / 饮料·冷 / 饮料·热」分流，每类只给 **3 个最常点的**；选一个主食后弹窗问「来个饮料吧 / 来个小食吧 / 直接结算」。
3. **结算**：任意时刻**长按「确认·结算」**都能进结算页，核对订单与价格。
4. **支付**：确认下单，生成取餐信息，到店取餐。

## 五、随时清空：回到主菜单 与 无操作自动清空

- **右上角「回到主菜单」**：任何时候点一下，**当前已选的全部内容立即清空**（订单、套餐配置、选中项、弹窗），并回到首页「想点套餐还是单点？」重新开始。
- **无操作自动清空**：默认 **60 秒**没有任何按键操作，网页会自动清空当前订单并回到首页（防止餐盒被人拿走或用户走神后，屏幕一直停在半成品订单上）。顶栏有倒计时提示，剩 10 秒会语音提醒。
  - 可在「设置 → 无操作自动清空订单」里改成 30 秒 / 120 秒，或直接关闭。

## 六、开箱与连接（实体盒）

- 盒内 RP2350 主板与三键已装好，USB 线从盒底/侧面出线口引出；板子与走线全部藏在盒内。
- 电脑用浏览器打开点餐网页（本地代理地址或云端链接）。
- 插上 USB，页面右上角「设置」勾选「使用实体点餐盒」，即可开始用三个键点餐。
- 没有实体盒时，设置里切回「使用屏幕按钮」，用页面大按钮或键盘（↑/↓/Enter，Shift+Enter 等效长按）操作。

## 七、常见问题

- **按键没反应**：检查 USB 是否插紧；确认用的是桌面版 Chrome / Edge；设置里已勾选「使用实体点餐盒」。
- **想中途放弃重来**：点右上角「回到主菜单」，或直接不操作等 60 秒自动清空。
- **菜单空白 / 加载慢**：首次加载需几秒；若长时间空白，检查网络或点页面「刷新菜单」（带冷却，避免频繁请求）。
- **想听热量**：部分商品语音会播报约多少千卡（基于麦当劳营养数据）。
- **想省钱**：内置优惠提示，结算前可留意领券。

## 八、安全与隐私

- 麦当劳 MCP 的调用密钥（Token）只在**服务端**，绝不进网页代码、公开仓库或截图。
- 默认使用**模拟支付**，走完流程不产生任何真实扣款。
- 若要**真实下单**：在「设置」里取消勾选「模拟支付」，确认下单时会通过麦当劳 MCP 创建一笔真实的到店订单（演示账号每日下单次数有限额，用完会提示并可一键切回模拟支付）。

---

*本说明对应硬件：嘉立创标准盒外壳（约 100×80×30mm）+ RP2350 主板 + 三键（上一个 / 下一个 / 确认·结算）+ USB 出线。*
