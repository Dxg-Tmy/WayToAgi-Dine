## 3. “卖得最好”的 Top3 怎么定

MCP 无销量，采用**双层规则**：

1. 自动权重：`爆款 3 > 人气 2 > 超值/立省 1.5 > 麦金卡/学生 1 > 普通 0`；
2. **人工置顶覆盖**：缓存里给每个类型写死一个 `top3` 名单，优先级最高（你想让哪三款当门面就写哪三款）。

## 4. 流程与文案（3 键，无回退）

按键语义（全程一致，实体/虚拟都一样）：

- 【下一个】＝ 在当前候选里循环切高亮（3→1）
- 【确定】＝ 选中/改选当前高亮项（**同一槽位只留一个，可反复改**）
- 【完成】＝ 确认本步、进入下一步；结算页＝去支付

> 无回退的容错：**未按“完成”前都能用“确定”改选**；一旦“完成”才前进。所以点错不用重来，改一下再“完成”即可。

### N0 开场 · 按时段

- 早餐 05:00–10:29｜午餐 10:30–13:59｜下午茶 14:00–16:59｜晚餐 17:00–20:59｜夜宵 21:00–04:59
- 屏幕三选：`① 套餐　② 主食（自己配）　③ 小吃·饮料`
- 语音：
  - 午餐/晚餐：「现在是{餐}时间，来份套餐，还是自己配主食？」
  - 下午茶/夜宵：「现在是{餐}时间，来点小吃，还是来杯饮料？」
  - 早餐：「早上好，来个套餐，还是来点小食？」
- 确定 → 进入对应池

### 分支 A · 套餐

- A1 套餐类型：`单人餐 / 学生套餐 / 随心配 / 拼盘·乐园`
  - 语音：「套餐有单人餐、学生套餐、随心配。要哪一类？」
- A2 该类型 Top3 循环高亮
  - 语音（例）：「单人餐最火的三款。第一款：精选单人餐三件套，40 块。」
- 确定选中 → 完成 → N6 支付

### 分支 B · 主食（自己配）

- B1 主食类型：`汉堡 / 炸鸡 / 其他`
  - 语音：「主食有汉堡、炸鸡。要哪一类？」（“其他”本店缺货则不出现在循环里）
- B2 该类型 Top3 循环高亮 → 确定选中
- B3 饮料断言推荐：
  - 非冬季：「主食有了，我们来一杯可乐吧。」
  - 冬季：「天气冷，我们来一杯锡兰红茶吧。」
  - 确定＝要得；下一个＝换一个（4 款内循环）；完成＝不要饮料
- B4 套餐升级（仅当选的主食有同名套餐时触发一次）：
  - 命中例：双层吉士汉堡→双层吉士汉堡套餐 ¥39.5；麦香鱼→麦香鱼套餐 ¥37.5；麦辣鸡翅→麦辣鸡翅4块套餐 ¥42；麦乐鸡→麦乐鸡套餐 ¥29.5
  - 语音：「你选的{主食}有个套餐更划算：{套餐名}，{价}。要换吗？」
  - 确定＝换；完成＝不换
- B5 → N6 支付

### 分支 C · 小吃·饮料

- C1：`小吃 / 饮料`
- C2 小吃 Top3（薯条/玉米杯/派）或饮料断言推荐
- 确定选中 → 完成 → N6 支付

### N6 支付

- 二维码**自适应尺寸**（`max-width:min(220px,60vw); aspect-ratio:1`），居中不裁切
- 完成＝我已支付

### N7 完成

- 取餐码/订单号；任意键 → 回 N0（新一单）
